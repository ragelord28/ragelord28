# Ragelord

Web3 builder based in India. I find new chains with strong liquidity, build NFT and DeFi products for them, and ship trading tools around those launches.

## Projects

**[0ops](https://0ops.trade)** — A collection of 999 NFT trading cards. Each card is one true fat-finger story. [@0ops_trade](https://x.com/0ops_trade)

**[HiMan](https://himan.space)** — A 3D generative NFT project of 10,000 cyber ronin, wired to HYPE. [@Enter_Himan](https://x.com/Enter_Himan)

**[Inkvestment Bankers](https://inkvestmentbank.ink)** — An investment bank on Ink.

**[Indian Option Market](https://github.com/ragelord28/indian-option-market)** — A Python research and decision-support desk for the Indian options market. It connects to Upstox for market data, includes opening-range and other options strategies, a backtester, paper trading, and a Streamlit dashboard. It does not place orders on its own.

## Stack

Python, Solidity, JavaScript, and HTML/CSS. Trading tools use the Upstox API, Streamlit, pandas, and pytest. NFT work includes Solidity contracts and browser-based generative work.
